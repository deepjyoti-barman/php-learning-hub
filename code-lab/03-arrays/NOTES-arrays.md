# Arrays

## What is an Array

An array is a special type of variable that can hold multiple pieces of data in a single variable, and hence they are
great for storing list of data.

## Key points of Arrays

- Versatile container that can hold various pieces of information - numbers, strings, booleans etc.
- Ordered collection
- Mixed data types
- Easy access (via indexes)
- Useful for grouping
- Dynamic sizing, in PHP an array can grow and shrink dynamically as needed

## Ways to Create Arrays and Accessing Values

```php
// Method 1
$names = array("John", "Jack", "Jill");

// Accessing array values
echo $names[1];
```

```php
// Method 2
$names = ["John", "Jack", "Jill"];

// Accessing array values
echo $names[1];
```
